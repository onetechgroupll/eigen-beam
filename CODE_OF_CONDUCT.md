# Code of Conduct

Contributors are expected to keep collaboration direct, respectful and focused on the work.

## Expected behavior

- Be precise and constructive in reviews.
- Separate blocking correctness/security issues from preferences or nits.
- Do not paste secrets, personal data or customer-sensitive information into issues, PRs or logs.
- Assume good intent, but verify claims with code, screenshots, logs or test output.

## Unacceptable behavior

- Harassment, discrimination or personal attacks.
- Sharing credentials, private customer data or confidential business information in repo surfaces.
- Publicly disclosing suspected vulnerabilities instead of using private vulnerability reporting (see SECURITY.md).

## Enforcement

The repository owner / One Tech Group maintainer decides access and enforcement for this project.
